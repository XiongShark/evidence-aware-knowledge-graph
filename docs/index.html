建模与溯源

课程和岗位分别维护 SKOS 能力词表，通过带复核状态的能力映射建立联系。RDF 将断言和支持判断建成独立资源，支持从判断回溯两侧的证据与来源偏移。OWL 定义分类和关系，SHACL 检查必填信息与证据引用。

同一岗位要求可拆出多条判断。汇总时按原始要求标识去重，保留各自的支持范围和欠缺条件。

项目验证范围

候选图谱覆盖 33 门课程、100 个岗位实例。百岗候选图按既定策略保留 1,714 条警告，SHACL 违规为 0。另在历史五岗基线上验证了 18 个注入故障及其恢复。两项实验范围各自独立。

网页中的匿名样例用于展示决策流程。约束通过说明数据结构满足校验条件，判断内容仍需结合来源复核。

SHACL · 每条判断须有证据和边界说明 
@prefix kg: <https://example.org/curriculum-workforce/> .
@prefix sh: <http://www.w3.org/ns/shacl#> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

kg:AssessmentShape a sh:NodeShape ;
    sh:targetClass kg:Assessment ;
    sh:property [ sh:path kg:evidence ; sh:class kg:Evidence ;
                  sh:minCount 1 ; sh:maxCount 1 ] ;
    sh:property [ sh:path kg:limitation ; sh:datatype xsd:string ;
                  sh:minLength 1 ; sh:minCount 1 ; sh:maxCount 1 ] .

查看完整的验证规则

SPARQL · 查找部分支持的要求及缺口 
PREFIX kg: <https://example.org/curriculum-workforce/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT ?requirement ?course ?judgment ?gap
WHERE {
  ?assessment a kg:Assessment ;
              kg:status "partial" ;
              kg:requirement/rdfs:label ?requirement ;
              kg:course/rdfs:label ?course ;
              rdfs:label ?judgment ;
              kg:limitation ?gap .
}
ORDER BY ?requirement ?judgment

匿名样例中返回 3 条判断，涉及 2 项原始岗位要求。

SPARQL · 区分判断条数与原始要求数 
PREFIX kg: <https://example.org/curriculum-workforce/>
SELECT (COUNT(DISTINCT ?assessment) AS ?assessments)
       (COUNT(DISTINCT ?requirement) AS ?requirements)
WHERE {
  ?assessment a kg:Assessment ;
              kg:requirement ?requirement .
}

匿名样例中 5 条判断去重后对应 3 项原始岗位要求。
